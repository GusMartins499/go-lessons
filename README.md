# Go Lessons

Notes and exercises from learning Go.

## Essential commands

| Command | Description |
| --- | --- |
| `go get <url>` | Install an external package |
| `go mod tidy` | Add missing packages, remove unused ones, and update `go.mod`/`go.sum` |
| `go fmt` | Format the code to the standard Go style |
| `go build` | Compile the project into a binary |
| `go run <file.go>` | Compile and run the application |
